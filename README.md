# Conrad.de Katalog Kategorisierer (Desktop App)

Standalone Windows GUI App für automatische Kategorie-Zuordnung (Parent / EFEU) in Conrad.de Produktchecklisten.

## Online Build via GitHub Actions (Kostenlos & Automatisch)

1. Neues privates oder öffentliches Repository auf [GitHub.com](https://github.com) erstellen.
2. Diese Dateien hochladen:
   - `conrad_app.py`
   - `requirements.txt`
   - `.github/workflows/build.yml`
3. Nach dem Hochladen startet GitHub Actions automatisch:
   - Unter dem Reiter **Actions** auf GitHub klicken.
   - Nach ca. 60–90 Sekunden ist der Build abgeschlossen.
   - Unter **Artifacts** die Datei `ConradCategorizer-Windows` herunterladen.
4. Die heruntergeladene `ConradCategorizer.exe` auf den Firmen-Laptop kopieren und per Doppelklick starten — ganz ohne Terminal oder Python-Installation!
